# Security policy

This project currently contains documentation only; there are no supported application releases.

Never post API keys, passwords, player records or private server configuration in issues or pull requests. Do not use production server data for examples or tests.

Use GitHub's private vulnerability reporting feature when available. If it is unavailable, open a non-sensitive issue requesting a private contact route without publishing exploit details or secrets.

Planned controls include server-side credential storage, native panel permissions, restricted provider destinations, archive validation, bounded downloads and isolated installation testing. These are design requirements, not implemented protections.
