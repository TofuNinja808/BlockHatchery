BlockHatchery

Free, open-source, self-hosted Minecraft server provisioning for Pterodactyl.

Planning and API-access validation. No application release is available. CurseForge support is pending application and approval.

What we intend to build

  • Modpack discovery and permitted server-file installation.
  • Exact Minecraft and loader selection with compatible Java runtimes.
  • Safe installation flows that preserve worlds and player data.

No planned sales, subscriptions or advertising. No public file mirror, bundled API keys or separate billing platform.

Provider permissions and author distribution choices come first. Implementation will wait until required access is verified. The source-code license will be selected before implementation is published.
