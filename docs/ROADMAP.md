# Roadmap

## Gate 1: credible project and access requirements
- [x] Document project purpose and non-monetized intent.
- [x] Identify official CurseForge third-party application route.
- [ ] Confirm project contact details and review application terms with the owner.
- [ ] Submit application; record submission separately from approval.
- [ ] Obtain authorized access and clarify independent self-hosting, storage and rate limits.
- [ ] Verify real catalog lookup, exact release resolution and permitted server-file access.

## Gate 2: provider and license readiness
- [ ] Verify required Minecraft, loader, Java and modpack sources.
- [ ] Select an open-source license for original implementation and audit dependency licenses.
- [ ] Record supported, blocked and deferred providers explicitly.

## Gate 3: implementation and isolated testing
- [ ] Implement minimal backend and panel integration.
- [ ] Prove real disposable-server installs and Java/loader compatibility.
- [ ] Prove authorization, interrupted-download safety and preservation tests.

## Gate 4: controlled release
- [ ] Document supported versions, limitations and manual recovery.
- [ ] Release only after acceptance evidence exists.

No delivery date or provider approval is guaranteed. A missing required API is a stop/reassessment gate, not permission to substitute an unauthorized proxy.
